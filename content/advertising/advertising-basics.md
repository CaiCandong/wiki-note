## 2. 投放生态：角色与链路

### 2.1 定义

投放（广告投放）指广告主通过平台把广告物料触达目标用户、并为此付费的过程。在线广告从**合约广告**（提前买断固定广告位，GD / CPD）演进到**竞价广告**（每次展示独立出价），以实时竞价（RTB）为核心的程序化交易生态随之形成。投放的核心问题可以概括为四个：**投给谁、在哪投、出多少钱、效果如何**。

### 2.2 生态角色

一次程序化广告投放涉及多个角色，它们不是替代关系，而是从机制、平台、角色和数据能力不同角度描述同一个生态：

| 角色 | 全称 | 服务对象 | 作用 |
| ---- | ---- | ---- | ---- |
| **DSP** | Demand Side Platform（需求方平台） | 广告主 | 投放操作与策略执行中心：定向、预算、出价、创意管理、数据报告 |
| **SSP** | Supply Side Platform（供应方平台） | 媒体 | 广告库存管理、设置底价、动态分配流量、最大化变现收益 |
| **ADX** | Ad Exchange（广告交易平台） | 撮合双方 | 类似股票交易所，RTB 拍卖场，把流量售卖给 DSP |
| **ADN** | Ad Network（广告网络） | 中间商 | 先向媒体采购库存再转售给买家，解决长尾流量分散采买问题 |
| **DMP** | Data Management Platform（数据管理平台） | 数据方 | 整合多方数据，提供人群标签、受众定向、用户画像 |
| **TD** | Trading Desk（采购交易平台） | 广告主 | 统一管理多个 DSP，分配预算、制定策略、查看报告 |

### 2.3 RTB 竞价流程

```
用户访问媒体 App/网页
        │（产生一次广告展示机会）
        ▼
媒体 / SSP ──广告请求──▶ ADX ──广播竞价请求──▶ DSP A、DSP B …
        ▲                           │（结合 DMP 人群数据评估流量价值，100ms 内出价）
        └──────竞胜广告物料回传────────┘
        │
        ▼
媒体加载展示广告 → 用户看到
```

1. 用户访问媒体，产生一次广告展示机会
2. 媒体向 ADX / SSP 发起广告请求并携带用户信息
3. ADX / SSP 将竞价请求（广告位信息、用户 ID 等）广播给多家 DSP
4. 各家 DSP 评估流量价值，决定是否出价及出价多少，返回出价和广告物料——整个过程需在 **100 毫秒**内完成
5. ADX 按出价排序选出胜者，把竞赢物料回传给媒体
6. 媒体加载并展示广告

**竞价规则**：胜者是出价最高的 DSP，但实际支付**第二高出价**加一个最小值——广义二阶拍卖（GSP，Generalized Second-Price），避免 DSP 相互压价，几乎所有互联网广告平台都采用。

除公开竞价（RTB）外，还有**私有交易市场（PMP）**（仅限受邀广告主参与）和**程序化直接交易**（绕过竞价，按固定 CPM 直销广告位）。

### 2.4 数据分层

- **第一方数据**：广告主自有用户数据（CRM、电商交易数据）
- **第二方数据**：需求方服务提供者在投放中积累的数据（DSP 的受众浏览/点击数据）
- **第三方数据**：非直接合作方数据（运营商、搜索人群、电商人群、社交人群数据）

## 3. 计费模式与出价机制

### 3.1 快速选型

| 场景 | 推荐计费 | 说明 |
| ---- | ---- | ---- |
| 品牌曝光、新品发布、素材测试初期 | CPM | 只在乎曝光量而非转化 |
| 吸引精准流量、引导互动（电商引流、应用下载） | CPC | 点击才付费 |
| 预算直接考核业务成果（注册、付费、线索） | CPA（变种 CPI / CPS） | 无转化不收费，媒体担全链路风险 |
| 固定位置长期包断 | CPD / GD | 按天 / 按约定展示量售卖的合约广告 |
| 效果广告规模化投放 | oCPX（oCPM / oCPC） | 算法智能调价，当前主流 |

### 3.2 三种基础计费模式

漏斗关系：先有展示（CPM）→ 再有点击（CPC）→ 最后转化（CPA），价格依次递增，风险从广告主逐步转移到媒体：

| 模式 | 计费依据 | 风险承担 | 适用 |
| ---- | ---- | ---- | ---- |
| **CPM**（Cost Per Mille） | 千次展示 | 广告主（曝光是否带来收益自担） | 品牌广告、视频广告 |
| **CPC**（Cost Per Click） | 每次点击 | 媒体担 CTR 风险（展示不点击不收钱），广告主担 CVR 风险 | 搜索广告、效果广告 |
| **CPA**（Cost Per Action） | 每次转化行为（付费/注册/下载/安装） | 媒体担全链路 | 效果广告；CPI（安装）、CPS（订单佣金）为变种 |

### 3.3 eCPM：竞价排序的统一标尺（经典公式）

**经典公式**：无论哪种出价模式，媒体最终都把出价换算成 **eCPM（estimated Cost Per Mille，预估千次展示收入）** 排序，eCPM 最高者赢得竞价：

```
eCPM = eCTR × eCVR × 出价 × 1000
```

**推导**：对一次展示，其期望价值 = 被点击的概率（eCTR）× 点击后被转化的概率（eCVR）× 每次转化的价值（出价），得到单次展示的期望收入；再 ×1000 换算成千次口径，让不同出价模式的广告放在同一把尺子上比较。

**各计费模式的退化形式**：

| 计费模式 | eCPM 计算 | 说明 |
| ---- | ---- | ---- |
| CPM | eCPM = CPM 出价 | 无 CTR/CVR 维度，直接可比 |
| CPC | eCPM = eCTR × CPC出价 × 1000 | 不考核转化，只乘点击率 |
| CPA | eCPM = eCTR × eCVR × CPA出价 × 1000 | 公式的完整形态 |

例：CPC 出价 2 元、预估点击率 1% → eCPM = 2 × 0.01 × 1000 = 20 元，胜过 CPM 出价 10 元的广告。

**要点**：

- **「预估」的含义**：eCPM 用的是媒体对每个流量（用户、场景、时间、广告位）的 **pCTR / pCVR 预估值**，不是历史真实值——不同流量的价值不同，这正是竞价「按次评估」的基础
- **防作弊机制**：统一按 eCPM 排序后，广告主无法「高 CPC 出价 + 故意做差素材白嫖曝光」——素材差 → 预估 CTR 低 → eCPM 低 → 拿不到量；同时倒逼广告主优化素材提高点击率
- **媒体端视角**：媒体千次展示收入 = eCPM ÷ 1000 × 展示次数，eCPM 即媒体对每次展示机会的价值定价

### 3.4 链路四要素与 oCPX

广告投放链路由四个「点」组成，不同计费模式的区别就是这四个点的组合方式：

| 关键点 | 含义 |
| ---- | ---- |
| **竞价点** | 媒体按什么标准选广告——统一换算成 eCPM 排序取最高 |
| **计费点** | 媒体按什么规则收钱——CPM 按展现、CPC 按点击、CPA 按转化 |
| **出价点** | 广告主在后台填什么价格——CPM 填千次展现价、CPC 填点击价、oCPX 填转化目标价 |
| **考核点** | 广告主真正在乎的指标——激活、付费、ROI，终极是 LTV |

- **CPM 模式**：四个点完全统一在千次展现，最简单直接
- **CPC 模式**：竞价点换算为 eCPM，计费点和出价点都在点击
- **oCPX（oCPM / oCPC）**：出价点与计费点**完全分离**——广告主只填转化目标价（如「一个激活 80 元」），系统通过 CTR/CVR 模型预估每个流量的转化价值智能调价，媒体实际仍按点击或展现收费，最终使真实转化成本贴近目标成本。前提：需回传转化数据供算法学习，适合效果广告规模化投放

## 4. 账户结构与投放操作

### 4.1 层级结构：计划—单元—创意

投放后台普遍采用「计划—单元—创意」三级结构（部分平台为账户—计划—单元—创意四级）：

| 层级 | 划分依据 | 关注点 |
| ---- | ---- | ---- |
| **计划层** | 投放目标 / 广告位（品牌曝光类、精准转化类、创意测试类） | 纵向对比不同版位的量级、CPC、CTR |
| **单元层** | 定向人群（核心人群、扩展人群、兴趣人群、地域人群） | 横向对比不同定向的优劣和人群质量 |
| **创意层** | 素材维度（图片、视频、图文） | CTR、CVR 及后端转化，优胜劣汰 |

注意：同一计划下避免同时上过多单元（单元间会互相抢量）。

**预算分配「7:2:1 法则」**：70% 给主力投放计划、20% 给测试计划、10% 灵活机动；单计划日预算不宜过低。新计划冷启动期（前 3 天）预算按目标消耗的 60%–70% 分配，稳定后逐步加量。

### 4.2 定向方式

| 定向 | 特点 | 使用要点 |
| ---- | ---- | ---- |
| **意图词定向（关键词）** | 最精准、成本低 | 投放初期优先跑，词包选 PV 高的，先投核心词再扩展 |
| **兴趣定向** | 量级大、成本较高 | 必须缓慢叠加，不能一次性全选 |
| **LBS 定向** | 适合有线下门店的行业（餐饮等） | 流量较小但成本可观；与地域定向互斥只能选一 |
| **常规定向** | 年龄、性别、学历、地域、平台、网络 | 上新计划时不宜过窄，否则跑不起量、测不出结果 |

### 4.3 频次控制

- **计划级频控**：按计划设置每个用户在一定周期（1/7/15/30 天或全周期）内的曝光次数；设置后不可再按单元设置
- **单元级频控**：默认继承计划频控，可单独修改
- 品牌曝光类计划常设「每天 1 次」，避免用户重复曝光疲劳

## 5. 核心指标

### 5.1 指标分层

| 层级 | 指标 | 含义 / 公式 | 健康参考 |
| ---- | ---- | ---- | ---- |
| 流量 | CPM | 千次曝光成本 | 行业中位约 $13 |
| 流量 | CPC | 单次点击成本 | 线索型约 $1.9 |
| 点击 | CTR | 点击量 ÷ 曝光量，反映素材/文案吸引力 | 行业中位约 2%，低于 1% 需排查素材或定向 |
| 转化 | CVR | 转化用户数 ÷ 点击量，反映流量精准度与落地页承接 | 约 2%–5% |
| 成本 | CPA | 总花费 ÷ 转化数 | — |
| 收益 | ROAS | 广告收入 ÷ 广告花费 | 电商健康值 ≥2.5 |
| 收益 | ROI | （总收入 − 全部成本）÷ 总投入（含产品成本、物流、佣金、人工） | 穿透销量看真实盈利 |
| 平台 | GPM | 千次曝光成交金额 | 平台最核心评估指标之一 |

**ROAS vs ROI 的用法**：两者不是对立关系，应分阶段使用——**测试期用 ROAS 快速试错**锁定潜力计划（ROAS 3:1 以上重点观察，低于 1:1 果断关停）；**稳定期用 ROI 盘总账**判断真实盈利（避免「高销量低利润」陷阱：高 ROAS 低 ROI 的广告保留小预算作引流款，高 ROI 的加大投放）。

### 5.2 分阶段指标侧重

| 阶段 | 核心目标 | 优先指标 |
| ---- | ---- | ---- |
| 冷启动（0–1 个月） | 跑通模型、建立认知 | 转化量/转化率、CTR、CPM |
| 放量期（1–3 个月） | 稳定获客 | CPA、CVR |
| 成熟期（3 个月+） | 提升利润 | ROAS、ROI、LTV |

⚠️ 原则：一次只盯 1–2 个核心指标，避免数据噪音干扰判断。

## 6. 冷启动与学习期

### 6.1 定义

- **冷启动**：新广告 / 新广告主 / 新素材因缺乏历史投放数据，模型无法精准预估 CTR、CVR，进而影响竞价排序与投放效果的问题。核心矛盾：模型依赖历史特征但数据缺失；平台既要探索新广告质量又要避免损害用户体验；广告主渴望快速起量
- **学习期**：平台为新广告分配的数据积累与模型校准阶段，期间系统给予流量倾斜，同时容忍较大预估偏差

### 6.2 各平台学习期标准

| 平台 | 学习期时长 | 冷启动成功标准 |
| ---- | ---- | ---- |
| Meta（Facebook） | 约 7 天 | 累计约 50 个转化事件 |
| Google Ads | 约 7–14 天 | 30–50 个转化，CPA 稳定 |
| TikTok Ads | 约 3–7 天 | 20–50 个转化，成本波动在目标出价 ±20% 内 |
| 腾讯广告 | 约 3–7 天 | 累计 6–20 个转化 |
| 百度信息流 | 约 3–7 天 | 模型预估趋于稳定，偏差率低于阈值 |

### 6.3 分层决策

| 情况 | 操作 |
| ---- | ---- |
| CTR ≥ 行业均值 70% 且呈上升趋势，CVR 接近目标值 50% 以上，后端成本逐日下降 | **继续投放并加量**：预算日增约 20%，优先拓展相似受众（Lookalike） |
| CTR 达标但 CVR 低 | 检查落地页加载速度 / 转化路径，A/B 测试 2 组差异化素材后观察 48 小时 |
| CVR 达标但 CTR 低 | 优化素材标题、前 3 秒内容 |
| 日曝光极低（<5000）且出价高于建议价 20%；CTR 持续低于行业均值 30% 无回升；转化成本超目标 3 倍且无下降趋势 | **立即暂停** |

### 6.4 大厂算法解法（了解即可）

先验值填充（Meta 层级贝叶斯先验）、元学习/迁移学习（阿里 COLD）、多任务学习（阿里 ESMM、腾讯 PLE）、Embedding 预训练（字节、Meta）、Uplift 建模、强化学习（Contextual Bandit、分层 RL 动态调整探索流量与出价）。

## 7. 常见优化手法

- **eCPM 优化**：效果广告优化的核心是提升 eCPM（经典公式见 §3.3），四个抓手——出价（计划出价）、素材（eCTR）、落地页（eCVR）、账户历史表现/信用质量
- **赛马逻辑**：多建计划（不同人群、创意、出价）广撒网，系统按 CTR、CVR、转化成本、GPM 实时表现给「赚钱」的计划更多流量，淘汰「亏钱」的计划；表现好加预算（可直接翻倍）、表现差关停
- **素材节奏**：每 7 天左右更新素材防疲劳；受众重叠度建议 <15%
- **扩量手段**：放宽定向、增加预算、新计划提价 1%–20% 抢量（起量后等成本回落）、多建差异化计划（不无脑复制）
- **数据诊断对照**：

| 现象 | 可能原因 | 优化动作 |
| ---- | ---- | ---- |
| CTR 低 | 素材无吸引力、前 3 秒无亮点、定向错位 | 优化素材 / 标题 / 关键词 |
| CTR 高但 CVR 低 | 落地页加载慢、广告承诺与页面不一致、受众不匹配 | 改落地页、筛选人群 |
| CPM/CPC 持续上涨 | 素材疲劳、受众重叠高、竞品加价 | 更新素材、控制频次（1.5–3 次）、检查重叠 |
| CPA 高但转化质量好 | 流量贵但准（「贵但值」） | 保留并慢慢降价 |
| CPA 低但质量差 | 假优化 | 砍掉，换考核目标 |
